Drivona Project
Project Overview
Drivona is a comprehensive web application designed to manage both front-end and back-end functionalities. The project includes a user-friendly interface and robust backend services, updated as of 4 months ago to enhance performance and features. It leverages modern development practices and tools to provide a seamless experience.
Features

Front-end and Back-end Integration: Updated to ensure smooth communication between client and server sides.
Documentation: Includes a dedicated docs folder for project documentation.
Prisma Support: Utilizes Prisma for database management, with recent updates to both front-end and back-end.
Environment Configuration: Provides an .env.example file for setting up environment variables.
